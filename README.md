# 微新注音（IdealismBopomofo）

盡量維持與微軟注音相同的操作習慣，同時解決微軟注音導致的以下問題:
1. **不會讓舊版軟體卡死**，微軟注音新版IME在舊版軟體上會有相容性問題
2. 可以刪除預設詞典，某些詞典可能一輩子用不到還會影響選字
3. 選字要更聰明，至少要比微軟舊版注音更好(用過舊版注音那個選字真的拉完了，爛到乾脆叫AI幫我寫一個輸入法)

## 實作內容

當然本人沒有讓Opus把微軟注音的所有功能都搬過來，只有本人自己比較常用的：
 - 微軟注音的選字操作方式
 - 全形標點符號的輸入
 - 輸入法整合器
 - "`U" 這種Unicode輸入方法
 - 自定義詞典

沒有太多客製化空間，因為本人不需要。
